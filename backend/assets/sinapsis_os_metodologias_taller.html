Fase 2 · Agéntica
Blueprint del agente
Lógica agéntica · Sinapsis OS
"¿Qué dispara, qué razona, qué ejecuta, cómo se controla?"
Entrada → Disparador del agente Razonamiento → Lógica de decisión Acción → Output concreto Control → Indicador de funcionamiento
🗑
Eliminar
El proceso no agrega valor. Quitarlo es más rápido que automatizarlo.
Si fricción ≥ 7 y el trabajo real no lo necesita
✂
Simplificar
Reducir pasos manuales antes de introducir tecnología.
Si fricción 4–6 y hay desperdicio evidente
⚡
Automatizar
El proceso es necesario, estable y repetible. Candidato para agente.
Si fricción ≤ 4 y el proceso ya está limpio
